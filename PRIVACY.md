# Privacy Policy

## Data Processing

All data processing in SignFlow occurs locally on your device. SignFlow does not:

- Collect analytics or telemetry.
- Send data to external servers.
- Include advertising SDKs.
- Upload certificates, provisioning profiles, or private keys.
- Track user behavior.

## Data Stored on Device

- Imported IPA files (in temporary workspaces, deleted after use).
- Signing identities (in the iOS Keychain, protected by device security).
- Application metadata (display name, bundle ID, version — for inspection history).

## Data Not Stored

- P12 passwords (exist only in memory during import).
- Private key material outside Keychain.
- Full provisioning profile binary data (only parsed metadata is retained).
